# Portfolio

Mini pet project на React + TypeScript + Vite.

## Быстрый старт

```bash
npm install
npm run dev
```

После запуска Vite покажет локальный адрес, обычно `http://localhost:5173`.

## Скрипты

```bash
npm run dev      # запуск dev-сервера
npm run build    # production-сборка
npm run preview  # просмотр production-сборки локально
```

## Структура

```text
src/
  assets/       # статичные ресурсы проекта
  components/   # переиспользуемые React-компоненты
  App.tsx       # основной экран приложения
  main.tsx      # точка входа React
  styles.css    # глобальные стили
```
